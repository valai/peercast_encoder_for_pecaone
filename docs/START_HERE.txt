ぺかわん コネクト

1. ZIPを右クリックし、「すべて展開」を選びます。
2. PeerCastStationとTailscaleを用意し、PCとスマホを同じTailscaleネットワークへ接続します。
3. このフォルダの「ぺかわん コネクト.exe」をダブルクリックします。
4. 「ペアリングQRを作成」を押し、スマホアプリ「ぺかわん」で読み取ります。
   チャンネルはスマホ側で選択してください。

必要なファイルは同梱しています。追加のダウンロードやスクリプト実行は不要です。
「app」フォルダはそのまま残してください。移動するときはこのフォルダ全体を移動します。
デスクトップから起動したい場合は「ぺかわん コネクト.exe」のショートカットを作成してください。

ウィンドウを閉じても待機を続けます。終了するときは、通知領域のアイコンから終了を選んでください。
詳しい導入手順は app\FIRST_RUN.md にあります。
ライセンスとソースコードの取得先は app\LICENSE と app\THIRD_PARTY_NOTICES.md にあります。
